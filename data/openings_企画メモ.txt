■ 竣工・開業ウォッチ 企画メモ(2026-10-11 作成)

【狙い】
  知名度のある場所の「変わる直前」を、他に映像が無い時期に出す。
  アイランドシティ中央公園が当たったのは、開園前に出せたから(開業後は公式写真と他人の投稿で埋まる)。
  対象は住宅以外すべて: 商業施設・ホテル・公園・複合ビル・空港・駅前・スタジアム。

【ツール】
  python tools/opening_watch.py            巡回して data/openings.json を更新、近い順に表示
  python tools/opening_watch.py --list     巡回せず表示   --kind 公園 で種別を絞る
  data/openings_watch.json                 名前で追う「注目案件」(★表示)。ここに足せば記事に出た時期を拾う

────────────────────────────────────────
【1案件ごとに持ちたい情報】(openings.json の各エントリに足していく)
  基本    正式名称・仮称 / 種別 / 住所と座標 / 最寄り駅・バス停 / 事業者(施主・運営) / 規模(店舗数・面積・客室数・公園ha)
  時期    着工 / 竣工 / 内覧会・プレオープン / グランドオープン  ※出典URLと確認日を必ず残す。「未定」も記録
  子連れ  キッズスペース・授乳室・おむつ替え / 遊具・水遊び・芝生 / フードコート・キッズメニュー / 駐車場・ベビーカー導線
  ネタ    「何が3倍になる」「何が初」のような一言で言える異常値(福岡空港=店舗数が約90→約270)
  現地    公道から撮れる位置(仮囲い・建築計画のお知らせ看板・全景が入る歩道橋など) / 撮影日と素材フォルダ
  関連    マップ上の既存スポットid(親施設・周辺の店) / 過去動画URL(before素材として引用できる)
  投稿    予定している型と回数(下記) / 投稿済みURL / 数字(再生・保存)

────────────────────────────────────────
【動画の3段階】1案件で最大3本。②が本命
  ① 発表・工事中(竣工の3〜6か月前)
     現地の仮囲い・看板・全景 + 公式発表の数字をテロップで。15〜25秒の短尺。
     文言は「ここに◯◯ができる予定」「公式発表によると」。噂ではなく予定として出す
  ② 開業直前(内覧会〜開業の1〜4週前)   ← 検索が一番増えて映像が一番少ない窓
     ほぼ完成した外観 + テナント一覧・開業日・駐車場・アクセス。保存を取りに行く回
     ①の素材を冒頭に数秒置くと「変わった」が一目で伝わる
  ③ 開業後(当日〜1週間)
     実訪問。子連れ設備(授乳室・キッズスペース・キッズチェア)=マップの価値そのもの。ここで赤ピン登録
  公園は②③がほぼ同時(内覧会が無い)。開園日の朝に行って同日〜翌日に出す

【優先順位のつけ方】
  知名度(その場所の名前だけで行きたくなるか) × 子連れ要素 × 近さ(時期・距離) で並べる。
  今の上位: 音羽公園(2027冬・水遊び・博多駅近く) / 東平尾公園 全域(2027春・ローラーすべり台) /
            はばたき公園 全面(2027年度・中央公園と同じ型) / 福岡空港 複合施設(2027夏・店舗数3倍) /
            三井アウトレットパーク福岡(2027春・九州最大) / 須崎公園2期(2027/3・市民会館跡)
  長期(2028〜): 九大箱崎跡地 第1期まちびらき(2028年度) / 今泉公園(2028年度)

【マップ側】
  開業前の案件は青ピンで登録し、「◯年◯月 開業予定」のバッジを出す(期間限定の金リングの応用。実装はこれから)。
  開業後に赤ピンへ。before/after の2本を同じスポットに紐付ける

【週次の運用】
  1. 週1で opening_watch.py を回し、★の時期が変わったもの・新規を見る(collab_watch と同じ日に)
  2. 「残り日」が ①=竣工90日前 ②=開業28日前 ③=開業当日 を切ったものをロケ候補に上げる
  3. 行く前に公式サイトで撮影ルールを確認(short-video スキルのコンプライアンス節)。工事現場は公道からのみ

【注意】
  ・大店立地法の日付は「届出+8か月」の最短ラインの推定。実際の開店はもっと後が普通
  ・公園の供用開始は前倒し・遅れが頻繁。投稿の直前に市のページで再確認
  ・現場の人・看板の個人名は映さない。建築計画のお知らせ看板は設計者名等が入るので寄りすぎない
