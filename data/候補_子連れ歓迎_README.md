## 1. 検索に使える条件(実際に確認したもの)

ホットペッパーグルメはエリアコード+条件コードのパスで一覧が出る。福岡は `SA91`、エリアは `Y7xx/Y9xx`、ページは `bgnN/`。

| 種類 | コード | ラベル | 使えるか |
|---|---|---|---|
| 設備条件 | `U031` | お子様連れ(店舗の「お子様連れ」欄が OK/歓迎/不可のいずれか入力されている店) | **使える(今回の主軸)**。例: `https://www.hotpepper.jp/SA91/Y706/U031/bgn2/`。※「お子様連れ不可」の店も混ざるので店舗ページの欄で除外が必要 |
| 設備条件 | `U006` | 座敷あり | 使える(U031 と組合せ可: `/SA91/Y706/U031/U006/` 形式は未検証、単独は可) |
| 設備条件 | `U005` | 掘りごたつ | 使える |
| 設備条件 | `U004` | 個室あり | 使える |
| 設備条件 | `U017` | バリアフリー | 使える(ベビーカーの代替指標) |
| 設備条件 | `U016` | 駐車場あり | 使える |
| 特集(こだわり) | `dncLY0093` | お子様連れ歓迎のお店 | 開くが、エリア指定しても県内全域から20件程度の特集ページで網羅性なし(補助用) |
| 特集(こだわり) | `dncLY0084` | 家族で行きたいお店 | 同上(特集ページ) |
| 特集(こだわり) | `dncLT0099` | 座敷・掘りごたつのあるお店 | 同上 |
| フリーワード | `FWT=` | お子様メニュー(5件)/ファミリー(4件)/お子様連れ歓迎(2件)/キッズメニュー(2件)/ベビーチェア(1件) | 店名・キャッチにしか効かず件数が極端に少ない(天神 Y706 で検証)。キッズチェア/キッズスペース/ベビーカー/子連れ/おむつ/授乳室は 0 件。使わない |

店舗ページ(`/strJxxxxxxxxx/`)の「お店情報」テーブルから取れる子連れ関連の欄: `お子様連れ`(OK/歓迎/不可 + 自由記述。例「離乳食持ち込みOK/お子様用椅子あり/お子様用食器あり/ベビーカー入店OK」)、`座敷`、`掘りごたつ`、`個室`、`バリアフリー`、`駐車場`、`その他設備`。
CSV の kids_flags は「設備欄:<お子様連れ欄の原文>」+ 本文中のキーワード検出(キッズチェア/お子様メニュー/お子様用食器/キッズスペース/ベビーカー/おむつ替え/授乳/離乳食。(設備欄)=お子様連れ欄に記載、(本文)=ページ内の別箇所に記載)+ 座敷/掘りごたつ/個室/バリアフリー欄の「あり」。

ぐるなびは bot 遮断(403)のため不使用。食べログは未使用(ホットペッパーの構造化条件で十分な件数が出たため)。

## 3. 既登録との突合方法

- 店名の正規化(NFKC・小文字化・空白/記号除去)で完全一致
- 住所の町名+番地(丁目-番-号)が一致し、店名の先頭3文字を共有(spots.json に address がある676件のみ有効)
- 店名の「核」(支店名「◯◯店」「本店」や【】内の宣伝文を除去)が包含関係 → 支店名が異なれば「別店舗(同ブランド既登録)」として候補に残し note に記載
- 一覧の店名に【閉店】【移転】が付くもの、店舗ページのタイトルに閉店/移転/掲載終了があるものは除外
- 店舗ページの「お子様連れ」欄が「お子様連れ不可」のものは除外

既登録と判定した 147 件の対応表は `候補_子連れ歓迎_hotpepper_既登録対応表.csv`(HP店名 → spot_id / 判定理由)。理由に「支店名未確認」が付くものは片方にだけ支店名があるケースで、別支店の可能性あり。spots.json は読み取りのみ(書き込みなし)。

## 5. 注意点

- 「お子様連れOK」はホットペッパーの入力項目で、店が自己申告したもの。実際の子供椅子の有無は kids_flags に「キッズチェア」が出ている店以外は未確認。
- 居酒屋・バル・貸切パーティー系が多い(ホットペッパーの掲載店の偏り)。昼に子連れで使える店を探すなら genre=カフェ/和食/中華/焼肉/ハンバーグ 等 + hours にランチ時間がある店で絞ると良い。
- 「お子様連れOK ：13歳以上～」のように条件付きの店があるので、kids_flags の原文を必ず確認。「お子様メニューや設備はございません」のような否定文もキーワード検出に引っかかるため、設備欄で否定語が続くものは「※否定文あり要確認」を付けた(本文検出分は未判定)。
- note の「チェーン(◯◯)」は既知チェーン名での推定、「多店舗(同ブランドN件)」は今回の取得内で同じ先頭語が3件以上あったもの。
- 住所→緯度経度は未取得(登録時に map-spot の手順でジオコーディング)。
- 取得日時点の情報。HP の店舗ページは更新されるので登録時に再確認。
